# STEP · Интернет-магазин спортивной обуви

Современный интернет-магазин спортивной обуви с полным функционалом: каталог, корзина, система аккаунтов и админ-панель.

## 🚀 Возможности

* **Каталог товаров** — 6 товаров с фото, названием и ценой
* **Страница товара** — детальное описание при клике на карточку
* **Корзина** — добавление, изменение количества, удаление, подсчет суммы
* **Система аккаунтов** — регистрация и вход для каждого пользователя
* **Админ-панель** — добавление и удаление товаров
* **Поиск** — фильтрация товаров по названию
* **Оформление заказа** — форма с именем и телефоном
* **Визуальный фидбек** — анимации при добавлении в корзину

## 🛠️ Технологии

* HTML5
* CSS3 (кастомный дизайн)
* JavaScript (чистый, без библиотек)
* Font Awesome для иконок
* Google Fonts (Inter)
* localStorage для хранения данных

## 📦 Установка

1. Скачайте файл `index.html`
2. Откройте его в браузере
3. Наслаждайтесь!

## 💾 Хранение данных

Все данные (пользователи, корзины, товары) хранятся в `localStorage` браузера. Данные не пропадают после обновления страницы.
